About Muse Code Remote

Muse Code Remote (MCR) provides an open-source web interface that mirrors the native Meta Muse Code terminal agent securely across any network without port forwarding.

How it works:

  1. Run the mcr daemon on your machine (Linux, macOS, NAS, WSL).
  2. The daemon establishes an outbound WebSocket link with this relay.
  3. Paste the generated session token in this Web UI.
  4. Your terminal session is piped directly to your browser with full VT100 colors and auto-resize.
